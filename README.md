## Project Overview

This project focuses on Financial Risk Analysis using customer financial data. It includes data preprocessing, risk categorization, feature selection, and interactive dashboard development.

## Internship

**Program:** Infosys Springboard Virtual Internship 7.0

**Milestone:** Milestone 3 — Dashboard Development

## Project Objectives

- Identify high-, medium-, and low-risk customer segments.
- Analyze financial and customer risk patterns.
- Compare risk across geography, employment, and loan purpose.
- Develop interactive dashboards for risk assessment.
- Support faster identification of risk concentration and customer patterns.

## Project Workflow

1. Data preparation and cleaning
2. Field validation and segmentation
3. Risk categorization
4. Visual design and layout
5. Interactive analysis and validation
